# Dotfiles

====================================================================
 Stow Dotfile Installer
====================================================================
This script uses GNU Stow to create symbolic links for a dotfile
from a managed directory into the user's home directory.

 Prerequisite: You need to have Stow installed.

 Directory Structure:
 ~/dotfiles/
 ├── zsh/
 │   └── .zshrc
 └── ... (other dotfiles)
